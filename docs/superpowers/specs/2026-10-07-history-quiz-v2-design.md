# 한능검 암기 앱 v2 설계 — 빈도 기반 복습, 완료 상태, 전 범위 카드

작성일: 2026-10-07 · 이전 설계: `2026-10-06-history-quiz-pwa-design.md` (여기 적지 않은 내용은 그대로 유지)

## 목표

- 틀린 카드는 더 자주, 다 외운 카드는 "완료"로 학습에서 빠지게.
- 하루 학습량은 가변: 많이 풀어도 볼 카드가 떨어지지 않게 — **날짜가 아니라 푼 카드 수(빈도) 기준**으로 복습 시점을 정한다.
- 카드를 한능검 심화 출제 범위 전체로 확장(총 1,500장 안팎), 기존 카드와 중복 없이.

## 복습 방식 (빈도 기반)

- 앱 전체 카운터 `tick` = 지금까지 학습을 끝낸 카드 수(모든 모드 포함). 카드 하나가 세션에서 끝날 때마다 +1.
- 카드별 기록: `{ stage, next, seen, flagged, lapses, streak, done }`
  - `next`: 이 tick 이후에 다시 볼 차례. `lapses`: 복습에서 틀린 횟수. `streak`: 연속 정답 복습 수. `done`: 완료.
- 간격(카드 수) `GAPS = [20, 50, 120, 300, 700]`.
- 일반 학습에서 카드가 세션을 끝냈을 때:
  - **처음 배우는 카드**: `stage 0`, 세션 중 틀렸으면 `next = tick + 10`, 아니면 `tick + 20`. 첫 학습 중 실수는 `lapses`에 넣지 않는다(처음 보는 카드는 모르는 게 정상).
  - **복습 중 틀림**: `lapses + 1`, `streak 0`, `stage 0`, `next = tick + 10`.
  - **복습 정답**: `streak + 1`, `stage + 1`(최대 4), `next = tick + GAPS[stage]`. `lapses ≥ 2`면 간격을 절반(올림).
- **자동 완료**: `lapses = 0`이고 `streak ≥ 3`(복습 3연속 정답), 또는 마지막 단계(`stage 4`)에서 다시 정답.
- **"이미 알아요"**: 즉시 `seen: true, done: true`.

## 출제

- **학습 시작**(일반): 완료가 아닌 카드 중 ① 차례가 된 카드(`next ≤ tick`, 많이 틀린 순 → `next` 빠른 순) ② 새 카드(파일 순서) ③ 아직 차례가 안 된 카드(`next` 빠른 순)로 7장. 하루 제한 없음. 모든 카드가 완료되기 전에는 비지 않는다.
- **자주 틀린 카드**: 완료 아님 & `lapses ≥ 1`, 많이 틀린 순으로 7장. 맞혀도 기록 변화 없음, 틀리면 "복습 중 틀림"과 동일 처리.
- **완료 카드 점검**: 완료 카드만 무작위 7장. 맞히면 변화 없음, 틀리면 완료 해제 + "복습 중 틀림" 처리.
- 두 연습 모드는 홈에서 들어갈 때마다 새 라운드: 이번 라운드에 푼 카드는 다시 나오지 않고 다 풀면 라운드 종료.
- 시대 필터는 모든 모드에 적용.

## 화면

- 홈: 다시 볼 카드 / 새 카드 / 완료 / 오늘 푼 카드, 시대별 "완료 / 학습 중 / 전체", 버튼 "학습 시작", "자주 틀린 카드 (N)", "완료 카드 점검 (N)".
- 학습: "이미 알아요" 버튼(점검 모드에선 숨김), 나머지 동일.
- 관리: "하루 새 카드 수" 설정 삭제. "완료 카드" 목록(접기) + 항목별 "완료 취소"(차례를 지금으로).

## 저장·호환

- localStorage: `progress`, `customCards`, `stats = { tick, date, count }`(오늘 푼 카드 수는 `date`가 오늘일 때 `count`). `settings`, `newToday` 키는 더 이상 쓰지 않는다.
- v1 기록: 기존 `stage`·`seen`·`flagged` 유지, `due`는 버리고 `next = 0`(바로 차례), 나머지 0/false.
- 백업 v2: `{ version: 2, progress, customCards, stats }`. v1 백업(`settings`, `newToday` 포함)도 불러오기 가능(무시).

## 카드 확장

- 먼저 시대별 **출제 주제 목록**(커버리지 맵)을 만들고 기존 584장과 대조해 빠진 주제만 채운다.
- 새 시대값 `통시대` 추가: 지역사, 세시풍속, 유네스코 유산 등 특정 시대에 묶기 어려운 주제.
- 새 카드에는 `tier`(1 = 빈출 핵심, 2 = 심화). 파일 순서: 기존 584장 → 새 tier 1(시대순) → 새 tier 2(시대순). 앱은 새 카드를 파일 순서로 내므로 빈출이 먼저 나온다.
- 중복 금지: 같은 문제(공백·문장부호 무시 비교) 금지, 이미 있는 사실을 다른 말로 다시 묻는 카드 금지(검토자가 확인). 같은 정답은 단서가 다르면 허용.
- 기존 카드 id 유지, 새 카드는 `c0585`부터.
