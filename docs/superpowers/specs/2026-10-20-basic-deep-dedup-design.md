# 기본 · 심화 나누기와 중복 카드 합치기 (v22)

작성일: 2026-10-20 · 앞선 설계: `2026-10-15-rounds-design.md`.

## 왜

- 라운드(v21)로 순서는 잡혔지만, 홈 숫자·시기·판별·기출형·자주 틀린 카드는 여전히 4,195장 전부를 셌다.
- 같은 사실을 방향만 바꿔 묻는 카드(효종 → 하멜 표착 / 하멜 표착 — 어느 왕 때? → 효종)가 따로 있어 공부할 양이 부풀었다.

## 기본 · 심화

- **기본** = 57–79회 기출에 한 번이라도 쓰인 카드(+ 내가 가져온 카드). **심화** = 나머지. 카드의 옛 `tier`(작성 때 추측)는 쓰지 않는다. tier 1 중 1,182장이 기출에 한 번도 안 나왔다.
- 근거(앞 시험으로 기본을 정하고 뒤 시험으로 채점, 카드 연결 기준 추정): 57–73회 hits ≥ 1(1,634장)만 알면 74–79회 약 85점, hits ≥ 2(886장)는 약 68점. 57–68회로 정하면 69–79회 77점. 기준은 '1번 이상'. 다음 시험 카드의 15%쯤은 앞 시험에 없던 카드라 심화도 남긴다.
- 홈 맨 위 [기본] [기본+심화] (localStorage `deep`, 처음 기본). 범위가 홈 숫자, 라운드, 시대별 표, 시기·판별·기출형·자주 틀린 카드, 하루 목표에 적용된다. 노트 카드 풀기·순서·사진·보기 후보는 전체 그대로.
- '심화만'은 두지 않는다: 기본 복습이 빠진다. 기본을 다 배운 뒤 기본+심화가 사실상 심화 공부.
- 기출 데이터를 못 읽으면(hits 없음) 전체로.
- 라운드 이름 '기출 라운드' → '기본 라운드'.

## 중복 합치기

- 후보: 같은 답·비슷한 문제(바이그램 dice ≥ 0.8), 판별(대상 → 사실)과 반대 방향 카드(사실 → 대상)의 같은 사실. 130쌍.
- 하나하나 읽고 정한 규칙:
  - 한쪽에 따로 떨어진 단서가 더 있으면 합치지 않는다(부분 겹침: 영고·사출도·흉년 → 부여 / 흉년 → 부여, 옥저 정복·계루부 → 태조왕 등 8쌍). 시대·연도·나라 같은 맥락 낱말은 단서로 치지 않는다.
  - 시대가 다르면 합치지 않는다(통시대의 연해주·상하이 지역사 카드는 일부러 따로 있다).
  - 남는 카드: 기출형 자료가 있는 판별 카드 → 내용이 더 많은 카드 → 기출에 더 많이 나온 카드 → 판별 → 낮은 id. 기출형 자료가 붙는 판별 카드는 하나도 줄지 않는다(710).
- 결과: 119장 합침, 4,195 → 4,076장. 기본 1,792 → 1,773장(둘 다 기본인 쌍 19개, 나머지는 한쪽이 심화).
- 없어진 카드의 기출 연결(`docs/content/gichul/*.json` → `gichul.json` 다시 만듦), 노트 항목 연결, 🔑 memo·🧠 assoc(남는 카드에 없을 때만, 4·9줄)을 남는 카드로 옮겼다.
- `merged.json` = { 없어진 id: 남은 id }. 앱이 시작할 때·백업을 불러올 때 학습 기록과 ✏️ 메모를 옮긴다(`mergeIds`): 둘 다 있으면 기억이 더 강한(s 큰) 기록, 메모는 둘 다 이어 붙임.
- `docs/content/card-coverage.md`는 그때의 분석 기록이라 옛 id를 그대로 둔다.

## 테스트

- 로직: `mergeIds`(옮김·둘 다 있을 때 join·입력 불변).
- 데이터: merged.json의 없어진 id는 카드에 없고 남은 id는 있음. 기존 검사(기출 연결, 노트 연결·시대, 기출형 ≥ 700, memo·assoc 형식) 통과.
