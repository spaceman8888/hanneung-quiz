# 빈칸 노트: 교재 요약 페이지를 빈칸으로 (v31)

작성일: 2026-11-22

## 왜

- 학습자: "핵심내용 사진의 내용과 레이아웃 그대로 빈칸 채우기를 만들어 줘. '왕건의 성장'이면 '?의 성장'으로 두고, 속으로 답을 말한 뒤 누르면 정답이 나오고, 맞았는지 틀렸는지 눌러서 나중엔 틀린 것만 풀게."
- 추가 요청:
  - 글자 수 힌트는 주지 않아요. 대신 누르면 그 말에 대한 힌트를 볼 수 있어요.
  - 연속으로 N번 맞힌 빈칸은 글로 바꿔서 빈칸을 조금씩 줄여요.
  - 중요하지 않은 말은 빈칸으로 만들지 않아요.
  - '그냥 보기'를 누른 말은 다시는 빈칸이 되지 않아요.
  - 맞음/틀림을 누른 말은 초록/빨강 글로 남아요. 강을 나갔다 다시 들어오면 다시 빈칸이 돼요.
  - 사진에 있는 내용은 모두 넣어요. 중요한데 빠진 사실은 더해도 돼요.

## 바꾼 것

- **데이터 (`blanks.json`):** 02–40강 39개 강, 빈칸 2,002개(강마다 35–60개)이고, 그중 왼쪽 칸 이름 빈칸은 283개예요. 사진에 없어서 ＋추가로 표시해 더한 사실은 97줄이에요. 파일 크기는 약 315KB예요.
  - 문법:
    - `{답::힌트}`는 빈칸이에요.
    - `{답::힌트::k}`는 왼쪽 칸 이름 빈칸이고, 설정에서 끌 수 있어요.
    - `+`로 시작하는 줄은 사진 밖에서 더한 사실(＋추가)이에요.
  - 구조: 강 → 단원(sections) → 표의 행(rows, `[왼쪽 칸, [오른쪽 줄…]]`)이에요. 작은 제목이 있으면 단원 아래에 sub가 들어가요.
  - 문장은 교재를 옮겨 적지 않고 우리 말로 다시 썼어요. 사진(`핵심내용/`, `핵심내용2/`)은 저장소에 올리지 않아요(.gitignore).
- **만든 방법:**
  - 강마다 작성 에이전트가 사진을 읽고 JSON을 썼어요.
  - 다른 검토 에이전트가 사진과 하나씩 대조해서 빠진 내용, 틀린 사실, 빈칸 선택, 힌트, 옆 글이 답을 알려 주는 경우를 고쳤어요.
  - 마지막으로 병합 스크립트가 강 순서로 합쳐 힌트에 답이 들어간 곳이 없는지 확인했어요(문제 0).
- **로직 (`logic.js`):**
  - `blankParts`: 줄을 글과 빈칸으로 나눠요.
  - `lectureRows`, `rowBlanks`: 행과 빈칸에 고정 id `강-단원-행-자리-번호`를 붙여요.
  - `gradeBlank`: `{ s: 연속으로 맞힌 수, l: 'ok'|'bad', d: 날, p: 그냥 보기 }`를 기록해요. '하루 1번만 셈'이 켜져 있으면 같은 날 다시 맞혀도 연속 수가 오르지 않아요.
  - `blankGraduated`, `blankActive`: 졸업했는지, 아직 빈칸인지 판단해요.
- **화면 (더보기 → 빈칸 노트):**
  - 강 목록: 남은 빈칸 수, 틀린 수, 진행 막대가 나와요.
  - 강 화면:
    - 교재처럼 단원 제목과 2열 표로 보여요.
    - 빈칸은 모두 같은 `?`예요. 지난번에 맞힌 빈칸은 초록 테두리, 틀린 빈칸은 빨강 테두리예요.
    - 빈칸을 누르면 아래 막대가 열려요. 💡 힌트 → 정답 보기 → ○ 맞음 / ✕ 틀림 순서예요.
    - 정답을 본 뒤에는 '이 말은 앞으로 빈칸 없이 그냥 보기'를 누를 수 있어요.
    - 졸업했거나 그냥 보기로 정한 말을 누르면 '다시 빈칸으로'가 나와요.
  - 보기 모드: 전체 / 남은 빈칸 / 틀린 것만. 이번에 채점한 빈칸이 있는 행은 모드가 바뀌어도 그 자리에 남아요.
  - 설정:
    - 졸업 기준: 연속으로 맞힌 횟수이고, 기본 2번이에요. 0이면 졸업하지 않아요.
    - 하루 1번만 셈
    - 왼쪽 칸 이름도 빈칸
    - 그냥 보기 모두 되돌리기
    - 졸업 모두 되돌리기
  - 뒤로 가기(버튼과 휴대폰 뒤로 가기): 강 → 강 목록 → 홈 순서예요.
  - 앱을 새로 고치면 늘 홈에서 열려요. 예전 화면의 history 상태가 남아 있으면, 뒤로 가기가 목록이 아니라 홈으로 가던 문제가 있었어요.
- **백업:** 백업 version 6에 `blankMarks`를 포함해요. 예전 백업도 그대로 복원돼요.
- **오프라인:** `sw.js`의 FILES에 `blanks.json`을 넣었어요.

  - 강마다 힌트 → 정답 → 맞음/틀림을 눌러 초록/빨강 글 1개가 남는 것을 확인했어요.
  - 뒤로 가기 버튼과 휴대폰 뒤로 가기 모두 강 목록으로 돌아갔어요.

  - 그냥 보기는 다시 들어가도 글로 남았고, '다시 빈칸으로'로 되돌릴 수 있었어요.
  - 강 화면에서 새로 고친 뒤 들어가서 뒤로 가면 강 목록으로 갔어요.
