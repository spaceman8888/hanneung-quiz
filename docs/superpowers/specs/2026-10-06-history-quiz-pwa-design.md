# 한능검 암기 앱 (PWA) 설계

작성일: 2026-10-06

## 목표

- 한국사능력검정시험 심화 1급 대비, 안드로이드 폰에서 짬짬이(5~10분) 암기.
- Quizlet "학습하기"처럼 즉시 퀴즈 → 틀린 카드 재출제 → 간격 반복 복습.
- 시험까지 1~3개월, 카드 500~800장 규모.

## 범위

포함:
- 학습 세션(객관식 → 주관식 단계), 간격 반복 스케줄, 시대별 진도
- 기본 카드(Claude 초안) + Quizlet 내보내기 텍스트 가져오기
- 오프라인 동작, 홈 화면 설치, 학습 기록 백업/복원
- 카드 "신고" 표시(오류 카드 수정용)

제외 (필요 시 추가):
- 연도순 배열 문제, 기기 간 동기화, 계정/로그인, 통계 그래프, 서버

## 구조

빌드 도구·프레임워크 없는 정적 PWA. GitHub Pages로 배포.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 3개(홈/학습/관리) + 스타일 |
| `app.js` | 화면 전환, 학습 세션, 스케줄, 가져오기, 저장 |
| `cards.json` | 기본 카드 데이터 |
| `sw.js` | 오프라인 캐시 |
| `manifest.json` | 홈 화면 설치 정보(이름, 아이콘) |
| `test.html` | 스케줄·파싱 로직 assert 테스트 (브라우저에서 열어 확인) |

## 데이터

카드:
```json
{ "id": "c0001", "front": "9서당 10정 정비", "back": "신문왕", "era": "통일신라", "type": "인물" }
```
- `era`: 선사, 고조선·초기국가, 삼국, 통일신라·발해, 고려, 조선 전기, 조선 후기, 개항기, 일제강점기, 현대
- `type`: 인물, 사건, 제도, 문화재, 단체, 기타
- 가져온 카드의 id는 `q` + 앞면·뒷면 해시(중복 가져오기 방지), era는 가져오기 화면에서 선택(기본 "기타").

학습 상태(카드별, localStorage `progress`):
```json
{ "c0001": { "stage": 2, "due": "2026-10-09", "seen": true, "flagged": false } }
```
- 저장소: localStorage. 학습 기록 유실 방지를 위해 관리 화면에서 JSON 파일 내보내기/가져오기 제공.
- 가져온 카드도 localStorage `customCards`에 저장.

## 학습 세션

1. 오늘 복습 대상(`due <= 오늘`)을 먼저, 그 다음 새 카드(하루 한도, 기본 20, 설정 가능)로 7장 묶음 구성. 홈에서 시대 필터 선택 가능.
2. 각 카드는 세션 내 단계를 가짐: 처음 보는 카드는 객관식(4지선다) → 맞히면 주관식. 복습 카드는 바로 주관식.
3. 객관식 오답 보기: 같은 시대·같은 유형 카드의 뒷면에서 무작위 3개(부족하면 전체에서).
4. 주관식 채점: 공백·구두점 제거 후 비교. 오답 판정 시 "맞은 걸로 처리" 버튼 제공(표기 차이 대응).
5. 틀리면 정답 표시 후 해당 카드를 2~3문제 뒤에 다시 삽입.
6. 묶음 내 모든 카드가 주관식을 맞히면 묶음 종료 → 다음 묶음 또는 홈.

## 간격 반복 스케줄

- 간격(일): `[1, 3, 7, 14, 30]`, `stage`는 인덱스.
- 세션에서 처음 틀림 없이 맞힌 복습 카드: `stage + 1`(최대 4), `due = 오늘 + 간격[stage]`.
- 세션 중 한 번이라도 틀린 카드: `stage = 0`, `due = 내일`.
- 새 카드를 세션에서 끝낸 경우: `stage = 0`, `due = 내일`.
- 날짜는 기기 로컬 날짜 기준 `YYYY-MM-DD` 문자열.

## 화면

- 홈: 오늘 복습 수 / 새 카드 수, 시대별 진도(학습한 카드 / 전체), 시대 필터, "학습 시작".
- 학습: 진행 표시(묶음 내 완료 수), 문제, 보기 또는 입력창, 정답 피드백, "신고" 버튼.
- 관리: Quizlet 붙여넣기 가져오기(시대 선택), 하루 새 카드 수 설정, 기록 내보내기/가져오기, 신고된 카드 목록.

## Quizlet 가져오기

- Quizlet 내보내기 기본 형식: 용어와 정의 사이 탭, 카드 사이 줄바꿈.
- 탭이 없으면 줄 단위로 건너뜀(건너뛴 줄 수 표시). 앞면·뒷면 앞뒤 공백 제거, 빈 값은 건너뜀.

## 카드 초안

- Claude가 시대별 빈출 주제로 약 500장 작성. 앞면은 시험 단서 키워드, 뒷면은 정답(짧게).
- 사실 오류 가능성 있음 → 신고 기능으로 표시, 이후 수정.

## 오류 처리

- localStorage 읽기 실패/손상 시 빈 상태로 시작하고 경고 표시(기본 카드는 `cards.json`에서 항상 복구됨).
- 기록 가져오기 파일이 잘못된 형식이면 기존 기록을 덮어쓰지 않고 오류 표시.

## 테스트

- `test.html`: 스케줄 계산(정답/오답/최대 단계), Quizlet 파싱(정상/탭 없음/빈 값), 주관식 채점 정규화를 assert로 검증.
- 화면: 브라우저 모바일 크기에서 학습 한 묶음 직접 진행해 확인.

## 배포

- GitHub 저장소 생성 → GitHub Pages 활성화 → 폰 크롬에서 접속 → "홈 화면에 추가".
- 업데이트 시 `sw.js`의 캐시 버전을 올려 새 파일 반영.
