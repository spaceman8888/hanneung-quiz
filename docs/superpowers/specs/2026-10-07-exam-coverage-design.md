# 기출 대조 + 순서 문제 + 보기 판별 — 설계

작성일: 2026-10-07 · 앞선 설계(v2, 시기 맞히기)에 추가. 앱은 객관식 전용, 답은 누르는 즉시 저장(v5).

## 목표

사용자가 문제를 직접 쓰지 않고도, 최근 심화 기출에서 묻는 내용을 앱으로 훈련할 수 있게 한다. 사진·처음 보는 사료는 남으므로 목표는 "1급 안정권".

## 1. 기출 대조 분석

- 자료: 국사편찬위원회 시험자료실 공개분 = 심화 57~79회(23회, 약 1,150문항) 문제지·정답표. 공공누리 4유형(출처표시·비상업·변경금지).
- 문제지 PDF와 렌더링 이미지는 작업 폴더에만 두고 저장소·앱에 넣지 않는다. 저장소에는 **사실을 우리 말로 정리한 분석 결과만** 둔다(사료·문항 문장 인용 금지).
- 회차별 분석 `docs/content/gichul/<회차>.json`: 문항마다 `{ q, era, kind, subject, subjectType, answerFact, clues, cards }`
  - `kind`: `판별`(대상 파악 후 옳은 설명 고르기) / `시기`(어느 왕·시기) / `순서` / `사이` / `사진`(정답 고르기에 사진·지도가 필수) / `기타`
  - `answerFact`: 정답 선지의 사실을 40자 이내로 다시 쓴 것
  - `clues`: 대상을 알아내는 단서 키워드(짧은 낱말, 3개 이내)
  - `cards`: 그 대상/사실을 이미 다루는 카드 id
- 종합 `docs/content/gichul-gaps.md`: 유형 분포, 대상 빈도, 시대별로 (a) 카드에 없는 대상, (b) 판별 카드로 만들 정답 사실, (c) 시기 카드로 만들 사실, (d) 순서 문제용 연도 사건.

## 2. 순서·시기 사이 문제

- 카드에 `year`(정수, 기원전은 음수) 추가: 사건·제도·단체·시기·문화재 중 한 해로 확립된 것만. 시대별 작성·사실검토.
- 홈 버튼 "순서 문제": 매번 새로 생성(복습 일정 없음).
  - `가장 먼저`: 연도가 서로 3년 이상 떨어진 4개 중 가장 이른 것.
  - `사이`: (가)·(나) 두 사건(6년 이상 차이) 사이에 있는 1개 + 바깥 3개.
  - 시대 필터가 있으면 그 시대와 바로 앞뒤 시대의 사건만.
  - 보기 문구: 시기 카드는 문제에서 "— 어느 …?"를 뗀 것, 나머지는 정답(이름).
  - 답한 뒤 각 보기 옆에 연도를 보여 준다. "모르겠어요" = 오답 처리.
- 선사·판별 카드는 대상이 아니다.

## 3. 보기 판별 카드

- 새 유형 `type: "판별"`, 새 필드 `group`(예: `고려 왕`, `조선 후기 인물`, `일제강점기 단체`).
- 카드 = 사실 하나: `front` = 대상 이름(예: `광종`), `back` = 그 대상에 관한 사실 문장(40자 이내).
- 화면: `<대상>에 대한 설명으로 옳은 것은?` 보기 = 정답 사실 + 같은 시대·같은 group의 **다른 대상** 사실 3개(부족하면 같은 시대 판별 카드). 같은 대상의 다른 사실은 절대 오답 보기가 되지 않는다. 판별 카드와 다른 유형 카드는 보기를 섞지 않는다.
- 일반 학습에 섞이고 복습·완료 규칙 동일. 홈 버튼 "보기 판별 (N)".
- 작성 원칙: 같은 group 안에서 사실이 대상 하나에만 맞도록(다른 대상에게도 맞는 사실 금지). 기출 정답 사실 우선.

## 4. 누락 보강

- 분석 (a)·(c)로 기존 유형 카드(단서 → 대상, 시기)를 추가. 기존 규칙(10자 정답, 단서 2~3개, 중복·역질문 금지) 그대로.

## 테스트

- 로직: 순서 문제 생성 불변식(보기 4개, 간격, 정답 위치, 사이 조건), 판별 보기(같은 대상 제외, group 우선, 유형 격리).
- 카드: `year` 정수 범위, 판별 카드 `group` 필수·back 40자 이내·(front, back) 중복 금지, 판별은 문제 중복 검사에서 제외.
- 화면: 폰 크기 브라우저 확인.
