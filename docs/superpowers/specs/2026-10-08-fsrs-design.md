# v7 설계 — FSRS 복습, 5지선다, 오답 해설, 시험일 계획, 카드 감수

작성일: 2026-10-08 · 이전 설계(v2 빈도 기반 복습)를 대체한다. 여기 적지 않은 내용은 그대로.

## 왜 바꾸나

v2는 푼 카드 수(tick)로 간격을 정하고, 복습 3번 연속 정답이면 카드를 "완료"로 영구 제외했다. 문제:
- 하루에 몰아 풀면 하루 안에 완료된다(잠을 한 번도 안 거친 기억).
- 완료 카드는 시험 날까지 다시 안 나와서 잊혀도 모른다.
- 망각은 시간에 따라 일어나는데 간격이 시간과 무관하다.

## 복습: FSRS-5

- Anki 기본 알고리즘인 FSRS-5(공개 기본 가중치)를 그대로 쓴다. 카드별 `{ s, d, last, due, lapses, flagged }`: 안정도 s(일), 난이도 d(1~10), 마지막 복습일, 다음 복습일(정수 날짜), 망각 횟수.
- 기억률 R(t) = (1 + 19/81 · t/s)^-0.5. 목표 기억률 90% → 다음 간격 = s일(최소 1일).
- 채점: 틀림·모르겠어요 = Again(1), 정답 = Good(3), 이미 알아요 = Easy(4). 세션 안에서 틀린 카드를 다시 맞히는 것은 기록하지 않는다(학습 단계 역할).
- 정답 연속 시 간격 대략 3 → 11 → 35 → 101일. 처음 틀린 카드는 다음 날.
- **완료** = s ≥ 21(3주 뒤에도 90% 기억). 완료 카드도 간격을 넓혀 계속 나온다. "완료 카드 점검" 모드는 필요 없어져 삭제.
- 모든 모드(학습·시기·판별·자주 틀린 카드)의 첫 답을 기록. 순서 문제는 기록 없음.
- 출제 순서: 오늘 복습(기억률 낮은 순) → 새 카드(파일 순서: 기본 → tier1 → tier2) → 미리 복습(기억률 낮은 순). 양을 제한하지 않는다는 v2 방침 유지.
- 이전 기록 이전: 본 카드는 오늘 날짜로 한 번 복습한 것으로 변환(완료 → Easy, 틀린 적 있음 → Again, 그 외 → Good), lapses·신고 유지.

## 보기·해설

- 보기 5개(시험과 같은 5지선다, 찍어서 맞힐 확률 25% → 20%). 순서 문제도 5개.
- 답한 뒤 오답 보기마다 그 보기의 실제 주인을 작게 표시: 판별 카드는 대상 이름, 일반 카드는 그 답을 가진 카드의 단서. 오답 하나하나가 구별 학습이 된다.

## 시험일 계획

- 관리에서 시험일 설정(`exam`, 백업 포함).
- 홈: `시험까지 D-n · 오늘 새 카드 x / 목표 k장`. k = ⌈남은 새 카드 / max(1, n − 7)⌉ — 시험 일주일 전까지 모든 카드를 한 번 배우고 마지막 주는 복습만.
- 홈: "지금 기억하는 카드: 약 N%" = 전체 카드 기억률 평균(안 본 카드 0). 시험 날 90% 이상이 목표.

## 카드 감수

- 시대별 감수: 사실 오류, 연도 오류(순서 문제 정답에 직결), 보기 판별에서 같은 group 다른 대상에게도 맞는 사실(정답 2개), 애매한 단서, 기출(57~79회) 빈출인데 빠진 내용.
- 결과는 수정·삭제·추가로 반영하고 기존 테스트 규칙을 모두 지킨다.
