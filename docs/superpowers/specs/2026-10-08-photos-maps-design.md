# 사진·지도 설계 (2단계)

작성일: 2026-10-08 · 앞선 설계: `2026-10-08-notes-design.md`(1단계 글 노트).

## 목표

기출 사진 문항(57~79회 61문항: 문화유산 40, 지역·지도 8, 국가 6, 화가 5)은 사진을 보고 이름·시대(백제/신라/고려…)를 알아보거나, 설명에 맞는 사진을 고르는 형식이다. 같은 형식으로 연습하게 한다.

성공 기준: 시험에 사진으로 나오는 문화유산(탑·불상·건축·도자기·그림·고분 유물·비석 등)과 위치를 묻는 지역이 카드로 들어가 복습 일정에 오르고, "사진 고르기"로 시험과 같은 사진 5지선다를 풀 수 있다. 모든 사진은 이용 허락이 확인되고 출처가 표시되며, 그 유산이 맞는지 검증된다.

## 카드 (cards.json에 추가)

| type | 추가 필드 | 화면 |
|---|---|---|
| `사진` | `img`(경로) · `credit`(출처 표시) · `kind`(탑/불상/건축/도자기/그림/고분·유물/비석·기타) · `period`(백제·신라·고구려·가야·통일 신라·발해·고려·조선 전기·조선 후기·선사 등 시험식 시대 이름) · `note`(정답 뒤 보여 줄 한 줄, 60자 이내) · `of`(그 유산을 다루는 기존 카드 id) | 사진 + `front` 질문, 보기 5개 = 다른 사진 카드 이름 |
| `지도` | `geo`([위도, 경도]) · `note` · `of` | 한반도 지도 + ● + `front` 질문, 보기 = 다른 지도 카드 이름 |

- `back` = 이름(10자 이내 규칙 유지), `era` = `of` 카드의 시대.
- 보기: 사진은 같은 `kind` 우선(탑은 탑끼리 — 시대 구별 연습), 지도는 같은 시대 우선. 사진·지도 카드는 다른 유형과 보기를 섞지 않는다.
- 오답 해설: 사진 카드의 오답 보기에는 그 보기의 `period`를 표시.
- 정답 뒤 `note`(시대·핵심 특징)를 보여 준다.
- 사진·지도 카드는 같은 질문 문구를 쓰므로 `front` 중복 검사·답 노출 검사에서 제외(정체성은 사진·좌표).
- 노트 연결: 새 카드는 `of` 카드가 처음 들어 있는 노트 항목의 `cards`에 추가 → 모든 카드 연결 규칙 유지. 노트 항목을 펼치면 그 항목의 사진을 작게 보여 준다.

## 사진 고르기 모드 (복습 일정 없음, 순서 문제처럼 매번 생성)

- `period` 하나를 골라 "다음 중 ○○의 문화유산은?" — 정답 = 그 period 사진 1장, 오답 = 다른 period 사진 4장(같은 kind 우선). 사진 5장을 2열 격자로.
- 답한 뒤 각 사진 아래에 `이름 · period`. "모르겠어요" = 오답. 시대 필터가 있으면 그 시대 사진만 정답 후보.

## 지도

- 바탕: Natural Earth 10m land(퍼블릭 도메인)를 경도 119~133°, 위도 32.5~44°로 잘라 투영(경도 × cos 38°)한 SVG path 하나(`map.json`).
- 점: `geo`를 같은 투영으로 찍는다. 대상 = 위치를 묻는 지역(통시대 지역 카드)과 장소가 핵심인 사건·전투(강동 6주, 삼포, 개항장, 주요 전투지 등) 중 한 점으로 표시되는 것. 넓은 영역(삼국 전성기 범위 등)은 제외.

## 사진 출처·검증

- 1순위: 국가유산청 Open API 이미지 중 `imageNuri`가 A(공공누리 제1유형: 출처 표시 시 자유 이용)인 것. `credit` = "국가유산청, 공공누리 제1유형".
- 2순위(국내 목록에 없는 해외 소장품 등): 위키미디어 공용의 퍼블릭 도메인 또는 CC BY/BY-SA 사진. `credit`에 저작자·라이선스.
- 유산 매칭은 공식 명칭·지정 번호로, 사진은 전경 위주로 고른다. 내려받아 긴 변 480px JPEG(품질 70)으로 줄여 `img/<카드 id>.jpg`.
- 검증: 사진을 보는 별도 검증 단계가 한 장씩 "이 유산이 맞는가"를 확인하고, 전체 사진을 한 화면에 모아 직접 훑는다.

## 오프라인

- 서비스 워커: `img/`는 별도 캐시(버전이 바뀌어도 유지)에 처음 볼 때 저장.
- 관리: "사진 모두 내려받기"(진행률 표시) — 오프라인 대비.
- 사진을 못 불러오면 사진 자리에 "사진을 불러오지 못했어요(오프라인)" 문구, 카드는 계속 풀 수 있다.

## 테스트

- 카드: 사진 카드 필드(img 파일 존재·credit·kind·period·note 길이·of 존재·era 일치), 지도 카드 geo 범위.
- 로직: 사진·지도 보기(같은 유형만, kind/시대 우선), 사진 고르기 문제 생성(정답 1장, 오답은 다른 period, 5장), 지도 투영(경계 안).
- 노트: 기존 "모든 카드 연결" 테스트가 새 카드에도 적용.
- 화면: 폰 크기에서 사진 카드·지도 카드·사진 고르기·노트 사진·오프라인 문구 확인.
