# 연상으로 외우기 · 내 메모 (v18)

작성일: 2026-10-12 · 앞선 설계: `2026-10-11-miss-help-design.md`.

## 왜

- 🔑 `memo`는 사실·논리 요령만 쓴다(말장난 금지). 사건 ↔ 왕처럼 이유 없이 짝지어진 카드는 논리 요령이 없어, 소리 연상(키워드법)이 가장 잘 듣는다.
- 남이 만든 연상보다 내 연상이 더 잘 떠오르는 사람도 있다. 문제마다 직접 적어 둘 곳이 필요하다.

## 🧠 연상 (`assoc`)

- 카드 필드. 한 줄, 70자 이하, 이모지·머리말 없음, tip·memo와 다름, tip이 있는 카드에만. JSON 키 순서는 memo(없으면 tip) 바로 뒤.
- 오답 화면에서 **[🧠 연상으로 외우기]** 버튼을 눌러야 보인다(오답 화면 줄이 이미 많다). 줄 맨 끝에 점선 테두리로.
- 소리 고리(답 이름과 소리가 비슷한 일상어) + 엉뚱한 장면. 말장난은 기억 장치일 뿐 뜻·유래처럼 쓰지 않는다. 담긴 사실은 모두 맞아야 하고, 헷갈리는 짝에도 똑같이 맞는 고리는 쓰지 않는다. 참사·피해자를 다루는 카드는 쓰지 않는다.
- 범위: 기출(57–79회)에 쓰인 카드 1,792장. 새 카드가 기출 빈도순으로 나와 실제로 만나는 카드가 대부분 여기다.
- 작성: 시대별 9묶음 작성 → 독립 검증(사실·유래처럼 읽힘·소리 고리·짝 충돌·취향·억지) → fix/drop 반영.

## ✏️ 내 메모 (`myNotes`)

- localStorage `myNotes` = { 카드 id: 글 }. 백업 내보내기·불러오기에 포함(`validateBackup`: 없거나 객체).
- `setMyNote(notes, id, text)`: 앞뒤 공백 제거, 빈 글이면 삭제, 원본 불변.
- 오답 화면: 'again' 다음, 🔑 앞에 `✏️ 글`(초록 테두리). 정답 화면: 메모가 있으면 보여 주고 자동 넘김을 멈춘다.
- [✏️ 메모] / [✏️ 메모 고치기] → 입력칸(300자) + 저장·취소. 저장하면 바로 위 줄에 반영.
- 자동으로 넘어가는 정답 화면(0.5초)에서는 메모를 새로 쓰지 않는다.
