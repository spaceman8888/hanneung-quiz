# 시험 계획 · 실전 채점 · 마무리 주간 (v23)

작성일: 2026-11-07 · 앞선 설계: `2026-10-20-basic-deep-dedup-design.md`.

## 왜

- 학습자는 직장인이에요. 평일 3시간, 나머지는 주말에 공부해요. 시험은 제81회(2026-11-28 토 10:00, 심화만)예요. 하루 목표가 `새 카드 ÷ 남은 날`이라 주말·평일 차이와 실전 시간을 반영하지 못했어요.
- 예상 점수는 카드 기억률로 낸 추정이에요. 실제 기출을 80분 재고 푼 점수가 앱에 들어가지 않아서, 실전에서 틀린 문항이 복습으로 이어지지 않았어요.
- 가이드는 "마지막 일주일은 복습만"이라고 하지만 학습 시작은 새 카드를 계속 냈어요. FSRS는 시험일을 몰라서, 지금 배운 카드의 다음 복습이 시험 뒤로 잡혔어요.
- "앱이 인터넷에서 일정·공부법을 확인"은 할 수 없어요. 서버 없는 정적 PWA라 historyexam.go.kr을 브라우저에서 읽을 수 없어요(CORS, 스크래핑은 사이트가 바뀌면 깨짐). 대신 2026-11-07에 확인한 일정을 `NEXT_EXAM`에 넣고, 릴리스 때마다 갱신해요.

## 시험 계획 (`studyPlan`, `assignMocks`)

- 오늘부터 시험일까지의 날을 단계로 나눠요. learn(시험 8일 전까지) → final(마지막 7일) → eve(전날) → exam. learn 끝은 이전 `dailyNew`와 같아요.
- 하루 시간은 `hours = { wd, we }`(기본 3·6시간, localStorage `hours`)로 정해요.
- 실전(80분 + 채점·오답 40분 = 120분)은 learn 단계의 일요일, final 단계의 토·일요일에 둬요. 회차는 최근 기출부터 하되 이미 푼 회차는 건너뛰어요. 마지막 실전은 앱 자료에 없는 최신 회차(81 − 1 = 80회)로, 처음 보는 시험으로 남겨 둬요.
- 새 카드는 learn 날들의 "실전을 뺀 시간"에 비례해 나눠요. 누적 반올림이라 합이 정확해요.
- 비용은 고정값이에요(`ponytail:` 표시). 새 카드는 처음 1분 + 복습 3번 × 20초 = 2분, 이미 배운 카드는 복습 1.5번(30초)으로 잡았어요.
- fit = 시간 안에 들어가는 새 카드 수예요. 모자라면 홈과 계획 화면이 "약 N장(R라운드까지)"과 "모두 배우려면 주말 하루 약 X시간"을 알려 줘요. 새 카드는 빈출 순이라 앞쪽이 우선이에요.
- 오늘 목표는 "오늘 시작할 때의 새 카드 수"로 계산해요. 공부하는 동안 목표가 줄어들지 않게 하려는 거예요(이전 `dailyNew`에 있던 문제).
- 화면
  - 홈 '오늘 할 일' 카드: D-day · 평일/주말 시간 · 단계, 복습 n장(약 분), 새 카드 k/목표, 실전(채점하기 버튼), 남는 시간에 할 일, 부족하면 ⚠.
  - '시험 계획' 화면: 시험일(관리에서 옮김), 제81회로 정하기 버튼, 평일·주말 시간, 날짜별 표, "이 계획은 이렇게 짰어요"(근거와 출처).

## 실전 채점 (`mockMisses`)

- 회차, 점수(선택), 틀린 번호(1~50 토글)를 넣어요. localStorage `mocks`에 `[{ n, date, score|null, wrong }]`로 저장해요. 같은 날 같은 회차를 다시 넣으면 덮어써요.
- `gichul.json` questions에 `n`(회차, 파일 이름), `q`(번호), `s`(대상)를 더했어요(`tools/build-gichul.mjs`). 57~79회는 틀린 문항이 무엇을 물었는지 보여 주고, 연결 카드를 모드 `mock`으로 풀게 해요(노트 카드처럼 ids 고정, 한 바퀴). 자료가 없는 회차는 점수만 기록해요.
- 홈 예상 점수 아래에 '실전 최근: n회 점수'가 나와요. 백업(v4)에 hours·mocks를 담아요.

## 마무리 주간 (`finalBatch`)

- 시험 7일 전부터 학습 시작은 "마무리 학습 시작"이 돼요. 새 카드 없이, 배운 카드를 손실 큰 순으로 내요. 손실 = (1 − 시험날 recall) × (1 + 기출 출제 수). 오늘 이미 답한 카드는 다음 날 다시 나와요(같은 날 복습은 효과가 거의 없어요).
- 새 카드가 필요하면 라운드 목록의 '풀기'로 직접 골라요.
