# 새 카드 한 바퀴 먼저, 연속으로 틀린 카드 우선 (v26)

작성일: 2026-11-08 · 앞선 설계: `2026-11-08-simple-home-design.md`.

## 왜

- 학습자: "일단 뭐든 새 카드를 먼저 한 번씩은 풀게 하는 게 중요할 것 같아. 그 뒤에 자주, 연속으로 틀리는 문제를 우선 풀게 하고 싶어."
- 시뮬레이션(11/9 → 11/28, 기본 1,773장, 57~79회, 평일 3·주말 6시간, 마지막 7일 마무리)

| 처음 볼 때 아는 비율 | 하루 몫 새 카드(v25) | 한 바퀴 먼저 | 한 바퀴 → 많이 틀린 카드 먼저 |
|---|---|---|---|
| 10% | 90.0 | 90.0 | 90.0 |
| 30% | 93.2 | 92.7 | 93.0 |
| 60% | 96.9 | 96.1 | 96.3 |
| 30%, 시간 60% | 79.1 | 79.1 | 79.1 |

  점수 차이는 1점 안쪽이라 학습자가 원하는 방식을 택했어요. 많이 틀린 카드부터 복습하는 쪽이 0.2~0.3점 조금 나았어요.

## 바꾼 것

- **큰 버튼(1단계):** `buildBatch(newFirst: Infinity)`. 기본 카드(공부 범위)를 모두 한 번씩 볼 때까지 새 카드만 내요. 오늘 틀린 카드는 지금처럼 20문제 뒤에 다시 나와요. 마무리 주간은 그대로 finalBatch예요.
- **`run`:** 채점된 답(세션의 첫 답)이 연속으로 틀린 횟수예요. `review()`가 기록하고 맞히면 0으로 돌아가요. 다시 푼 답은 결국 맞힐 때까지 반복되니 세지 않아요.
- **복습 순서(buildBatch due, weakBatch):** 틀린 적 있고 완료 전인 카드를 run이 큰 순 → miss가 큰 순 → 잊은 순으로, 그다음 나머지를 잊은 순으로 내요.
- **2번 이상 연속으로 틀린 카드를 또 틀리면:** 🧠 연상이 저절로 펼쳐지고, 맨 위에 "N번 연속 틀린 카드예요. 같은 방법으로 반복하기보다 🧠 연상과 🔑 외우는 법을 소리 내어 읽고, ✏️ 메모에 내 말로 적어 보세요."가 떠요. 반복만 하는 것보다 외우는 방식을 바꾸게 하려는 거예요. 이전에는 복습에서 2번 틀렸을 때(lapses)에 같은 안내가 떴어요.
- **하루 목표(🔥):** 한 바퀴를 도는 날(남은 새 카드가 있거나 오늘 배운 새 카드가 있음)은 오늘 몫의 새 카드예요(남은 수를 넘지 않게). 복습은 그날 보너스예요. 다 돈 뒤에는 틀린 카드 복습(남은 것 + 오늘 한 것)이에요.
- **실전은 선택:** 계획에서 실전 2시간을 빼지 않아요(`MOCK_MIN` 삭제). 일요일 몫이 토요일과 같아졌어요.
- **홈:** 1 새 카드 한 바퀴(본 카드 / 전체) · 2 연속으로 틀린 카드 · 3 나머지 복습. 2·3은 한 바퀴 전에는 '한 바퀴 뒤에'로 보여요. 버튼 글씨는 "1. 새 카드 한 바퀴 · 오늘 n / 몫장"이에요.
