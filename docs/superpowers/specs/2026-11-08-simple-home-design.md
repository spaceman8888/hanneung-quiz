# 단순한 홈: 큰 버튼 하나, 오늘 진행률, 🔥 연속 (v25)

작성일: 2026-11-08 · 앞선 설계: `2026-11-08-new-first-design.md`.

## 왜

- 학습자: "D-20은 보이는데 뭘 눌러서 진행해야 할지 모르겠어. 추천 계획대로 공부할 수 있는 버튼이 있으면 좋겠어." 기능이 늘면서(라운드, 시대, 연습 버튼 8개, 숫자 4칸, 꿀팁, 시대별 표) 첫 화면이 복잡해졌어요.
- 성취감과 계속 하고 싶은 마음: 오늘 얼마나 했는지가 보이고, 끝내면 축하받고, 이어지는 기록이 있어야 해요.
- 시안 세 가지(체크리스트, 스테이지 맵, 진행률 링) 중 학습자가 **A: 버튼 하나와 오늘 체크리스트**를 골랐고, 실전 기출은 '선택'으로 해 달라고 했어요(기출문제집이 아직 안 옴).

## 첫 화면

- D-day(마무리 주간 D-7~, 시험 날 D-DAY), 날짜와 오늘 시간, "오늘 N% 완료 · 예상 점수 약 M점", 진행률 막대.
- 큰 버튼은 처음엔 "오늘 공부 시작", 오늘 하나라도 풀었으면 "이어서 하기", 마무리 주간엔 "마무리 학습 시작"이에요. 아래 작은 글씨는 지금 단계예요. 누르면 늘 전체 시대로 풀어요(시대 선택을 비움).
- 오늘 할 일: 1 새 카드 n/목표 · 2 틀린 카드 복습 n장 · 3 나머지 복습(여유 되면) · 실전 기출(선택, 진행률 제외, 채점하기). 끝난 줄은 ✓예요. 마무리 주간은 '마무리 학습 n/목표', 전날은 '가볍게 1시간'과 '준비물·일찍 자기', 시험 날은 안내 한 줄이에요.
- 🔥 연속: "🔥 n일 연속 · 오늘 채우면 n+1일" / "🔥 n일 연속 목표 달성".
- '더보기'(details): 시험 계획, 실전 채점, 기출형, 자주 틀린 카드, 시기, 판별, 순서, 사진, 핵심 노트, 가이드, 관리·백업, 그리고 라운드 줄, 공부 범위(기본/기본+심화), 기록(숫자 4칸·예상 점수·기억률), 시대별 공부(시대 선택은 연습 버튼에만, 시대 줄은 그 시대 학습), 버전.
- 오늘의 꿀팁 줄은 없앴어요(가이드에 그대로 있어요).

## 진행률과 단계 (`dayGoal`, `todayState`)

- 1단계: 목표 = 오늘 새 카드 목표 + 틀린 카드 복습(지금 남은 것 + 오늘 한 것), 한 것 = min(오늘 새 카드, 목표) + 오늘 한 틀린 카드 복습. 3 나머지 복습은 보너스예요.
- 마무리 주간: 목표 = min(배운 카드 수, 오늘 시간 ÷ 20초), 전날은 60분이에요. 한 것 = 오늘 채점한 복습 수.
- 오늘 카운트를 stats에 넣었어요: count(맞힌 답), ans(모든 답), fresh(새 카드), rev(복습), weakRev(그중 틀렸던 카드), cheered. 날짜가 바뀌면 0부터 세요(`st()`). 예전에는 stats를 펼쳐 이어 써서 전날 값이 남을 수 있었어요.
- 단계는 1 새 카드 남음 → 2 틀린 카드 복습 남음 → 3 나머지 복습 남음 → 4 자유 학습이에요. 묶음이 바뀔 때 단계가 올라가면 "✓ 1. 새 카드 끝! 이제 2. 틀린 카드 복습"을 알려 줘요. 진행 표시줄에는 라운드 대신 단계가 보여요. 묶음(7장) 단위라 한 묶음 안에서 단계가 넘어갈 수도 있어요.

## 목표 달성과 🔥 (`bumpStreak`, `streakNow`)

- 오늘 처음 100%가 되면(오늘 답한 게 있을 때만) cheered를 기록하고 streak을 올려요. 어제 달성했으면 +1, 아니면 1이에요. 다음 묶음으로 넘어갈 때 축하 화면이 나와요: 🔥 연속, 오늘 문제 수·정답률·새 카드·복습, [여유 복습 계속하기][홈으로]. 홈에서 처음 알아챈 경우(묶음 중간에 나감)는 화면 없이 기록만 해요.
- streak은 localStorage `streak` { last, n }에 저장하고 백업 v5에 담아요.

## 내 판단으로 정한 것

- 진행률 100%에 3 나머지 복습과 실전은 넣지 않았어요(학습자가 말한 "여유 되면"과 "선택"에 맞춤).
- 🔥는 공부한 날이 아니라 목표를 채운 날로 세요(성취감). 하루 빠지면 1부터 다시 세요.
- 레벨·별 점수는 넣지 않았어요(B안 요소, 학습자가 고르지 않음).

## 테스트

- 로직: dayGoal(1단계·초과 새 카드·마무리·배운 카드 수 상한·전날·시험 날), 연속(달성·같은 날 두 번·하루 빠짐), 백업 검증(streak).
- 화면(390px): 시험일 없음 → 계획 안내와 '학습 시작'. 1단계 95%에서 이어서 하기 → 목표 달성 축하(🔥 2→3일) → 홈 ✓와 '🎉 오늘 목표 달성!'. 더보기에서 시대 고려 + 보기 판별은 고려만, 큰 버튼은 전체. 마무리 주간 문구. 콘솔 오류 0.
