# 라운드 (v21)

작성일: 2026-10-15 · 앞선 설계: `2026-10-12-study-science-design.md`.

## 왜

- 카드가 4,195장이라 끝이 안 보여 진도가 막힌다. 하루 목표도 기출에 한 번도 안 나온 2,403장까지 넣어 계산해 두 배 넘게 부풀어 있었다(D-60에 76장 → 기출만 34장).
- 사용자가 '한국사 오답노트' 앱처럼 핵심 문제를 묶은 라운드로 먼저, 많이 풀고 틀린 것만 다음으로 넘기기를 원했다.

## 설계

- **라운드** = 고른 시대(전체 = 모든 시대 섞음)의 카드를 기출 빈도순(byHits)으로 묶은 것. 기출(57–79회)에 쓰인 카드를 먼저, 안 쓰인 카드(심화)를 뒤에 따로 묶는다. 각각 100장 이하로 고르게 나눈다(203장 → 68·68·67, 끝에 3장짜리가 남지 않게).
  - 전체: 기출 1–18(1,792장, 기출 문제 100%) + 심화 19–43. 시대별: 기출 1–3 + 심화 1–4.
  - `rounds(cards, hits)`, `currentRound` = 아직 안 푼 카드가 있는 첫 라운드.
- **학습 시작**: 복습(시대 전체) → 지금 라운드의 새 카드 → 그 밖의 새 카드. `buildBatch`의 `round` 옵션으로 시대를 여러 개 골라 섞을 때도 지금 라운드 안에서 섞는다. 라운드 끝 묶음의 남는 자리는 다음 새 카드가 채운다.
- **틀린 것만 넘기기** = FSRS 그대로. 틀린 카드는 다음 날 복습으로 따라오고, 맞힌 카드는 잊을 때쯤에만 다시 나온다. 100장 전체를 다시 푸는 회독은 넣지 않았다(복습을 늘린 정책이 모두 점수가 같거나 낮았다, 지난 시뮬레이션).
- **오답** = `miss`(모든 오답, 처음 볼 때 틀린 것도). 기존 `lapses`는 배운 뒤 틀린 것만 세서, 첫 회독 직후 라운드 오답이 비어 버린다. `lapses`는 '복습에서 N번 틀린' 안내에 그대로 쓰고, v21 전 기록은 `miss`가 `lapses`에서 시작한다. 자주 틀린 카드·홈 개수도 `miss` 기준(가이드 '틀린 적 있고 아직 완료 안 된'과 맞음).
- **홈**: 통계 아래 라운드 줄(`기출 라운드 3 / 18 · 64/100 · 오답 12 ›` + 진행 막대), 누르면 라운드 목록.
- **라운드 목록**: 라운드마다 풀이·완료·오답 + [풀기(복습할 카드 + 새 카드만)] [오답만(틀린 적 있고 완료 안 된 카드, 한 바퀴)]. 심화는 접어 둔다. 지금 라운드는 굵은 테두리.
- **완료 알림**: 학습 중 라운드가 넘어가면 다음 묶음 위에 `🎉 기출 라운드 1 완료! 틀린 N장은 복습으로 다시 나와요.`
- **하루 목표**: 남은 기출 카드 기준(다 배우면 나머지 카드), `(기출 카드 N장 남음)` 표시.

## 테스트

- 로직: `rounds`(기출 먼저·고르게 나눔·빈 입력), `currentRound`, `buildBatch` round(여러 시대 섞여도 라운드 먼저, 복습은 그 앞), `miss`(첫 오답 포함, 옛 기록), `weakBatch`·`counts.weak`가 첫 오답 포함.
- 화면(390px): 홈 라운드 줄·목표 34장, 라운드 1 끝 3장 → 다음 라운드로 넘어가며 완료 알림, 라운드 목록·오답만, 고려만 골랐을 때 고려 라운드(87·87·85 + 심화 4개).
