# 기출형 연습·기출 우선순위·예상 점수·과신 보정 (v13)

작성일: 2026-10-10 · 앞선 설계: `2026-10-08-fsrs-design.md`.

## 왜

- 기출 판별 문항(670/1,150)은 대상 이름을 숨기고 단서만 준 뒤 그 대상의 옳은 설명을 고르게 한다. 앱은 "단서 → 이름"과 "이름 → 설명"을 따로만 연습했다(전이 적합 처리: 시험과 같은 처리를 연습해야 시험에서 꺼내진다).
- 기출에 나온 카드 1,090장이 파일 곳곳에 흩어져 있어, 새 카드를 다 못 배우면 빈출 카드를 놓친다.
- "기억하는 카드 %"는 시험 점수와 이어지지 않고, 학습자는 자기 실력을 과대평가한다.
- "이미 알아요"는 풀지 않고 16일 뒤로 미루고, 5지선다는 찍어도 20%가 맞는다 — 모두 Good/Easy로 기록돼 간격이 부풀었다.

## 1. 기출형 문제 (모드 `chain`)

- 판별 카드 J(대상 S, 사실 F)를 이름 없이 낸다: `(가) <자료>` + "(가)에 대한 설명으로 옳은 것은?", 보기 = 판별 보기(pickChoices 그대로).
- 자료 후보: ① 기출 판별 문항 중 대상이 S이고 시대가 J와 같은 문항의 단서 키워드 묶음(S 이름이 들어간 키워드는 빼고 2개 이상 남을 때, `·`로 연결) ② 일반 카드(판별·시기·사진·지도 제외) 중 `back = S`이고 같은 시대인 카드의 `front`.
- 정답 누설 금지: 자료와 F가 핵심어(2자 이상, 흔한 서술어·국명 제외, 조사 뗀 형태 포함)를 공유하면 그 후보는 버린다. 후보가 없는 J는 기출형에 안 나온다.
- 문제마다 후보 하나를 무작위로 보여 준다(같은 사실을 여러 단서로 — 부호화 다양성).
- 채점·복습 일정은 J의 FSRS 기록 그대로(첫 답 기록). 출제 순서는 다른 모드와 같다(오늘 복습 → 새 카드 → 미리 복습), 시대 선택 적용.
- 답한 뒤 `(가) = S`를 보여 주고 자동으로 넘기지 않는다. 오답 보기에는 그 보기의 대상(기존 해설).
- 기출 단서 묶음은 별도 검증 단계가 "그 대상을 가리키는가"를 확인하고 틀린 묶음은 원본(`docs/content/gichul`)에서 고친다.

## 2. 새 카드는 기출 빈출 순

- `gichul.json`의 문항별 연결 카드로 카드별 출제 횟수를 세고, 기본 카드를 횟수 내림차순(같으면 기존 파일 순서)으로 정렬해 새 카드 순서로 쓴다. 여러 시대 섞기는 시대 안에서 이 순서를 지킨다.

## 3. 기출 기준 예상 점수

- 지난 기출 문항(연결 카드가 있는 것) 각각을 "연결 카드 기억률 평균 r로 알고, 모르면 5지선다 찍기"로 본다: 정답 확률 = 1 − (1 − r)·4/5. 점수 = 100 × 평균.
- 홈: `기출 기준 예상 점수 약 N점 (추정 · 1급 80점) · 점수 올리기 좋은 시대: E +M점`. E = 놓치는 점수가 가장 큰 시대, M = 그 시대 문항을 모두 맞혔을 때 오르는 점수.
- 시대 선택과 무관하게 전체 기준. 실제 문항이 카드보다 어려워 다소 높게 나올 수 있음 → "추정" 표기.

## 4. 과신 보정

- **이미 알아요**: 누르면 바로 넘기지 않고 "답을 골라 확인" 상태가 된다. 맞히면 Easy(4), 틀리면 Again(1) + "확실하다고 했는데 틀렸어요" 안내(고확신 오답은 바로잡으면 오래 기억된다 — hypercorrection).
- **오래 걸린 정답 = Hard(2)**: 보기가 보인 뒤 답까지 걸린 시간이 `6초 + 글자 수 × 0.05초`(문제·자료·보기 글자 합)를 넘으면 Hard. 화면이 가려졌던(앱 전환) 문제는 시간을 재지 않는다. 피드백에 "고민한 카드라 조금 일찍 다시 나와요".
- **먼저 떠올리기**(관리 → 학습 방식, 기본 꺼짐): 카드 문제의 보기를 가리고 "보기 열기"를 눌러야 보인다. 이미 알아요를 눌러도 열린다. 순서·사진 고르기에는 적용 안 함. 설정은 localStorage `recallFirst`.

## 데이터

`gichul.json` = `{ questions: [{ era, cards }], sets: [{ era, subject, clues }] }` — `tools/build-gichul.mjs`가 `docs/content/gichul/*.json` + `cards.json`에서 만든다. questions: 연결 카드가 모두 존재하는 문항, era = 연결 카드의 최빈 시대. sets: 판별 문항 중 대상이 판별 카드 front인 것, era = 연결 카드 중 그 대상 판별 카드의 시대(없으면 문항 시대). 불러오기 실패 시 기출형은 카드 자료만, 예상 점수 숨김, 순서는 파일 순서.

## 테스트

- 로직: 출제 횟수, 빈출 정렬(안정), 예상 점수(안 본 카드 = 20점, 다 기억 = 100점, 올리기 좋은 시대), 누설 판정, 기출형 색인(시대 일치·이름 키워드 제거·누설 제외), 채점 등급(sure/slow).
- 데이터: gichul.json 카드 id 존재, sets 키워드에 대상 이름 없음.
- 화면: 폰 크기에서 기출형 풀기, 이미 알아요 확인, 먼저 떠올리기, 예상 점수 줄.
